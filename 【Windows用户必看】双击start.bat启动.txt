============================================================
 AnythingMindmap - Windows 启动说明
============================================================

【最重要的一步】

双击本项目文件夹中的：

    start.bat

不要只复制 start.bat，必须保留整个项目文件夹。


一、第一次启动会自动做什么

1. 检查项目文件夹是否可写；不可写会马上提示，而不是装到一半才失败。
2. 检查电脑里是否已有 Python 3.10 或更高版本，并确认它能创建虚拟环境。
   应用商店的 python.exe 占位符、缺少 venv 组件的精简安装都会被自动跳过。
3. 如果都没有可用的 Python，会自动下载官方 Python 3.12.10 并装到项目内。
   若项目目录装不上（权限、安全软件、已注册的同版本 Python），
   安装器会自动换一种更保守的方式重试；仍失败则改用官方嵌入式 Python。
4. 下载时会优先使用国内镜像，失败后自动切换：
   华为云镜像 -> 清华镜像 -> 阿里云镜像 -> Python 官网
5. 每个 Python 安装包都会进行 SHA-256 校验，防止下载内容被篡改。
6. 在项目内创建 .runtime 运行环境（能用系统 Python 时优先建虚拟环境）。
7. 自动安装 requirements.txt 中的全部 Python 依赖，国内镜像顺序：
   清华 PyPI -> 阿里云 PyPI -> 华为云 PyPI -> 官方 PyPI
8. 装完会做两层自检：先确认依赖可导入，再确认应用模块本身可导入。
   任一步不通过会自动强制修复重装一次，仍失败才会报错。
9. 环境准备完成后自动启动服务，并打开浏览器。

第一次启动需要联网，通常需要几分钟。网络较慢时可能需要更久，
请保持黑色命令窗口打开，不要重复双击 start.bat。


二、运行要求

- Windows 10 或 Windows 11，64 位系统。
- 首次启动必须联网。
- 项目文件夹必须可写，建议放在 D:\AnythingMindmap 等普通目录。
- 不建议放在 C:\Program Files，因为普通用户通常没有写入权限。
- 自动安装不需要管理员权限，也不会修改系统 PATH。
- 模型 API 和 MinerU Token 需要联网调用，即使本地环境已安装完成。


三、启动成功后

浏览器会自动打开：

    http://localhost:8000

首次使用时，请打开页面右上角的“设置”，填写：

- OpenAI 兼容模型服务的地址、模型名和 API Key。
- MinerU Token；配置后可用云端 OCR 识别扫描件。没有 Token 时会尝试用 PyMuPDF 读取 PDF 文字层。

使用期间不要关闭黑色命令窗口。关闭窗口后，本地服务也会停止。


四、如何停止

在黑色命令窗口中按：

    Ctrl + C

或者直接关闭该窗口。


五、安装失败时怎么看原因

错误原因和处理建议会以中文显示在黑色命令窗口中。

常见原因包括：

- 网络断开，或者代理设置不正确。
- 国内镜像暂时不可用。程序会自动切换，最终也会尝试官方源。
- 项目目录没有写入权限（程序会在开始时就提示，不会装到一半才失败）。
- Python 安装包或依赖文件被安全软件拦截。
- Python 版本与依赖不兼容。

详细安装日志位于：

    .runtime\bootstrap\python-install.log

启动失败的中文原因和处理建议位于：

    .runtime\bootstrap\bootstrap.log

如果使用普通 Python 且依赖环境损坏，可以关闭程序后删除：

    .runtime\venv

然后重新双击 start.bat。程序也会在依赖自检不通过时自动强制修复一次，
通常不需要你手动删除。

如果需要完全重新安装，可以删除整个：

    .runtime

再重新双击 start.bat。删除 .runtime 不会删除上传的资料和学习数据。


六、注意事项

- 不要使用旧版本的 mindmap.zip 或 mindmap 2.zip。
- 更新程序时请复制整个新版项目文件夹，不要只替换 start.bat。
- 上传资料、知识树、设置和复习进度保存在 knowledge-compiler\data。
- 备份资料时请备份 knowledge-compiler\data 文件夹。
- 如果命令窗口显示中文乱码，请确认使用 Windows 10/11 自带的 PowerShell。
